# Privacy

Stored locally in your browser: journal trades, alerts, notifications, session notes, cached price snapshot (IndexedDB); settings, watchlist, favorites, checklists (localStorage).

Sent to third parties: only market-data requests to Binance and, if needed, Bybit. They see your IP address, user agent and the pair symbols requested. No account, analytics, cookies or tracking.

Exported: CSV and JSON backups contain only the data above. ScalprX never stores exchange API keys, private keys or seed phrases and never asks for them.
